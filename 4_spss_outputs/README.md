# SPSS Outputs

This folder contains the Version 2 IBM SPSS Statistics files used for the final statistical analysis of the IoMT Encryption Simulation study.

## exported_report

This folder contains the human-readable exported version of the SPSS results.

### SPSS_analysis.pdf

PDF export of the final SPSS statistical output. It contains the descriptive statistics, assumption testing, group comparisons, post hoc tests, nonparametric tests, pairwise comparisons, charts, and clear-text exposure results used to support the dissertation findings. :contentReference[oaicite:0]{index=0}

## output

This folder contains the working SPSS data and output files.

### iomt_encryption_analysis_ready.sav

SPSS data file containing the final 40-environment Version 2 analysis-ready dataset used to perform the statistical tests.

### SPSS_analysis.spv

Native SPSS Viewer output file containing the complete statistical analysis results, tables, charts, and test output generated by SPSS.

## syntax

This folder contains the SPSS syntax used to perform the Version 2 statistical analysis.

### SPSS_analysis.sps

SPSS syntax file containing the commands used to analyze the final Version 2 dataset and generate the statistical results.

Together, these folders preserve the final SPSS dataset, analysis commands, native output, and exported PDF report used for the dissertation.
