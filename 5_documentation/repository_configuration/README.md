# Repository Configuration

This folder documents repository-level configuration files used by the Version 2 IoMT Encryption Simulation project.

## .gitignore

The `.gitignore` file is stored at the root of the repository and tells Git which local, temporary, or generated files should not be tracked or uploaded to GitHub.

The current `.gitignore` excludes the following categories of files that are not required to be stored in the repository.

### Python Bytecode and Cache Files

Python automatically creates bytecode and cache files while scripts are running. These files are generated automatically and are not part of the study source code.

The excluded patterns are:

- `__pycache__/`
- `*.py[cod]`
- `*$py.class`

### Python Virtual Environments

Local Python environments are excluded because they contain machine-specific package files and can be recreated from the documented software requirements.

The excluded folders are:

- `.venv/`
- `venv/`
- `env/`
- `ENV/`

The required Python packages are documented in `requirements.txt`.

### Python Tooling and Testing Caches

Temporary files created by Python development, testing, and code-analysis tools are excluded because they are not required for reproducing the study.

The excluded patterns are:

- `.pytest_cache/`
- `.mypy_cache/`
- `.ruff_cache/`
- `.coverage`
- `htmlcov/`

### Local Environment and Secret Files

Local environment files are excluded because they may contain machine-specific settings or sensitive configuration information.

The excluded patterns are:

- `.env`
- `.env.*`

The `.env.example` file is specifically allowed if one is added for documentation purposes.

### Jupyter Temporary Files

Jupyter Notebook checkpoint files are excluded because they are automatically generated temporary files.

The excluded folder is:

- `.ipynb_checkpoints/`

### IDE and Editor Files

Settings and temporary files created by local development environments are excluded because they are specific to the user's computer and are not required for reproduction.

The excluded patterns are:

- `.vscode/`
- `.idea/`
- `*.swp`
- `*.swo`

### Operating-System Files

Files automatically created by operating systems are excluded because they contain local system metadata rather than study data or source code.

The excluded files are:

- `.DS_Store`
- `Thumbs.db`
- `desktop.ini`

### Temporary and Backup Files

Temporary working files and editor backup files are excluded to prevent incomplete or unnecessary files from being committed to the repository.

The excluded patterns are:

- `*.tmp`
- `*.temp`
- `*.bak`
- `*~`

### Generated Condition Datasets

The condition-specific transmission datasets generated by the Python scripts are excluded from GitHub because of their combined file size.

The excluded folders are:

- `2_sample_data/unencrypted/`
- `2_sample_data/ecc/`
- `2_sample_data/rsa_she/`

These folders are generated locally when the experimental scripts are run. The original 40 synthetic source files remain stored in `2_sample_data/source_original/`, while the measurement results and validation evidence derived from the generated condition datasets are preserved in `3_output_data/`.

## Purpose

The `.gitignore` keeps the repository focused on the files needed to document and reproduce the Version 2 study, including the Python scripts, original source data, measurement results, validation reports, SPSS files, and supporting documentation.

It also prevents generated condition datasets, local machine settings, temporary files, caches, and potentially sensitive environment files from being committed accidentally.
